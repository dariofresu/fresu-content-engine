Connect your platforms the easy way

For every platform it's the same 3 moves: ① create its (free) developer app — one time, you're the vendor — ② paste that app's two keys into your Cloudflare backend, ③ press Connect. Do it next to Claude and you'll never be stuck. ← back to the planner

Connected: 0 of 6
1 · X (Twitter) ~10 min
  1. Open developer.x.com, sign in with the posting account, accept the Free tier, create a Project + App.
  2. In the app: User authentication settings → Set up: permissions Read and write · type Web App · Callback URI https://fresu-content-engine-auth.fresu-dario.workers.dev/auth/x/callback 📋 · Website https://dariofresu.github.io/fresu-content-engine/ 📋 → Save.
  3. It shows the OAuth 2.0 Client ID and Client Secret — paste them into Cloudflare (link in the green box) as secrets X_CLIENT_ID 📋 and X_CLIENT_SECRET 📋.
  4. On the Connect page press Connect next to x → approve → done.
2 · LinkedIn ~15 min
  1. Create the LinkedIn app (name e.g. Fresu Content Engine 📋, attach your company Page).
  2. Products tab → request Share on LinkedIn and Sign In with LinkedIn using OpenID Connect (instant approval).
  3. Auth tab → Authorized redirect URLs → add https://fresu-content-engine-auth.fresu-dario.workers.dev/auth/linkedin/callback 📋
  4. Copy Client ID + Client Secret (same Auth tab) into Cloudflare as LINKEDIN_CLIENT_ID 📋 and LINKEDIN_CLIENT_SECRET 📋.
  5. Connect page → Connect next to linkedin → approve.
LinkedIn sessions last ~60 days — when it expires you just press Connect again. One click, no keys.
3 · Facebook + Instagram ~25 min · one app for both
Before starting: Instagram must be a Business/Creator account linked to your Facebook Page (Meta Business Suite → Settings → Linked accounts).
  1. Create the Meta app: use case Other → type Business. It stays in Development mode forever — that's correct.
  2. Add product Facebook Login for Business → Settings → Valid OAuth Redirect URIs → https://fresu-content-engine-auth.fresu-dario.workers.dev/auth/meta/callback 📋
  3. App Settings → Basic: copy App ID and App Secret into Cloudflare as META_APP_ID 📋 and META_APP_SECRET 📋.
  4. Connect page → Connect next to facebook + instagram → approve the popups. Your Page and Instagram account are detected automatically.
4 · YouTube ~20 min
  1. Create a Google Cloud project (name fresu-content-engine 📋), then enable the YouTube Data API v3.
  2. OAuth consent screen: External → fill name + emails → save → press Publish app (must say In production, or the connection dies weekly).
  3. Credentials → Create credentials → OAuth client ID → Web application → Authorized redirect URI: https://fresu-content-engine-auth.fresu-dario.workers.dev/auth/youtube/callback 📋
  4. Copy the Client ID + Client Secret into Cloudflare as GOOGLE_CLIENT_ID 📋 and GOOGLE_CLIENT_SECRET 📋.
  5. Connect page → Connect next to youtube → Google warns "unverified app" → Advanced → continue (it's your own app) → approve.
Default quota ≈ 6 uploads/day.
5 · TikTok ~25 min + a few days' review
  1. Register at developers.tiktok.com → Manage apps → Create app.
  2. Add products Login Kit and Content Posting API, scopes video.upload, video.publish 📋, redirect URI https://fresu-content-engine-auth.fresu-dario.workers.dev/auth/tiktok/callback 📋
  3. Copy Client Key + Client Secret into Cloudflare as TIKTOK_CLIENT_KEY 📋 and TIKTOK_CLIENT_SECRET 📋.
  4. Connect page → Connect next to tiktok → approve.
  5. Submit the app for audit. Until approved, posts arrive as private — you tap "make public" in the TikTok app; afterwards they go out public automatically.
6 · Website editing (GitHub token) ~3 min
  1. Open GitHub → new fine-grained token: name fresu-content-engine-planner 📋, expiration 1 year.
  2. Repository access → Only select repositories → fresu-content-engine; Permissions → Contents: Read and write. Generate.
  3. Copy the token → open the planner → ⚙ Settings → paste → Save.
