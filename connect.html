Connect your platforms step by step

Work top to bottom — easiest first. Every value you need is a click-to-copy chip. Do this next to Claude (in chat or with the Chrome extension) and you'll never be stuck: Claude watches your screen and tells you exactly what to press. ← back to the planner

Connected: 0 of 6
1 · X (Twitter) ~10 min · easiest
  1. Open developer.x.com dashboard and sign in with the account that should post. Accept the free tier.
  2. Create a Project + App (any names, e.g. fresu-content-engine 📋).
  3. In the app: User authentication settings → Set up → permissions Read and write → type Web App → Callback URL https://dariofresu.github.io/fresu-content-engine/ 📋 → Website https://fresuelectronics.com 📋 → Save.
  4. Go to the Keys and tokens tab. You need 4 values: API Key, API Key Secret (top section — Regenerate if hidden), and Access Token & Secret (click Generate — must say "Created with Read and Write permissions").
  5. Open your repo's Secrets page and add each one — names must match exactly: X_API_KEY 📋 X_API_SECRET 📋 X_ACCESS_TOKEN 📋 X_ACCESS_SECRET 📋
🤖 Then tell Claude: "X secrets are in" — Claude sends a test post and fixes anything that errors.
2 · LinkedIn ~15 min
  1. Open LinkedIn → create app. App name e.g. Fresu Content Engine 📋, attach your company Page, add any logo, create.
  2. Products tab → request Share on LinkedIn and Sign In with LinkedIn using OpenID Connect (both approve instantly).
  3. Auth tab → Authorized redirect URLs → add http://localhost:8765/callback 📋
  4. Copy the Client ID and Client Secret from the Auth tab.
  5. On your PC, in a terminal in the repo folder, run python scripts/authorize_linkedin.py CLIENT_ID CLIENT_SECRET 📋 (replace the two values). A browser opens — approve — the terminal prints the two secrets.
  6. Add them at repo Secrets: LINKEDIN_ACCESS_TOKEN 📋 LINKEDIN_AUTHOR_URN 📋
LinkedIn tokens last ~60 days — when posts start failing, redo step 5–6 (2 minutes). Claude will remind you.
🤖 Then tell Claude: "LinkedIn secrets are in".
3 · Facebook + Instagram ~30 min · one app for both
Before starting: your Instagram must be a Business or Creator account linked to your Facebook Page (Instagram app → Settings → Business tools; or Meta Business Suite → Settings → Linked accounts).
  1. Open developers.facebook.com → Create app → use case Other → type Business → name e.g. Fresu Content Engine 📋.
  2. The app stays in Development mode — that's correct forever (it posts only to your own pages).
  3. Open Graph API Explorer → select your app → Get User Access Token → add permissions: pages_manage_posts, pages_read_engagement, pages_show_list, instagram_basic, instagram_content_publish, business_management 📋 → Generate token, approve the popups, copy the token.
  4. In a terminal in the repo folder run python scripts/authorize_meta.py APP_ID APP_SECRET SHORT_TOKEN 📋 (App ID/Secret are in the app's Settings → Basic). It prints the three values.
  5. Add at repo Secrets: META_PAGE_ID 📋 META_PAGE_TOKEN 📋 IG_USER_ID 📋
🤖 Then tell Claude: "Meta secrets are in".
4 · YouTube ~20 min
  1. Open Google Cloud → new project, name fresu-content-engine 📋.
  2. Enable YouTube Data API v3 for that project.
  3. OAuth consent screen: External → fill app name + your email twice → Save. Then — important — press Publish app so status says In production (in Testing mode your connection dies every 7 days).
  4. Credentials → Create credentials → OAuth client ID → Web application → Authorized redirect URI: http://localhost:8765/callback 📋
  5. In a terminal in the repo folder run python scripts/authorize_youtube.py CLIENT_ID CLIENT_SECRET 📋 → browser opens (it will warn "unverified app" — click Advanced → continue; it's your own app) → approve → terminal prints the refresh token.
  6. Add at repo Secrets: YT_CLIENT_ID 📋 YT_CLIENT_SECRET 📋 YT_REFRESH_TOKEN 📋
Default quota ≈ 6 uploads/day — plenty for scheduled Shorts.
🤖 Then tell Claude: "YouTube secrets are in".
5 · TikTok ~30 min + a few days' review
  1. Register at developers.tiktok.com → Manage apps → Create app.
  2. Add products Login Kit and Content Posting API; scopes video.upload, video.publish 📋.
  3. Redirect URI: https://dariofresu.github.io/fresu-content-engine/ 📋
  4. In a terminal run python scripts/authorize_tiktok.py CLIENT_KEY CLIENT_SECRET https://dariofresu.github.io/fresu-content-engine/ 📋 → approve in browser → you land back on your planner with ?code=… in the address bar → copy that code into the terminal.
  5. Add at repo Secrets: TIKTOK_CLIENT_KEY 📋 TIKTOK_CLIENT_SECRET 📋 TIKTOK_REFRESH_TOKEN 📋
  6. Submit the app for review/audit. Until approved, posts arrive as private — you tap "make public" in the TikTok app. After approval they publish public automatically.
🤖 Then tell Claude: "TikTok secrets are in".
